# Maria Fernanda Ribeiro — Portfólio

Portfólio pessoal desenvolvido em HTML, CSS e JavaScript, inspirado na estética visual do template Norvin usado como referência.

## Estrutura do site

1. Sobre
2. Experiências
3. Habilidades
4. Contatos

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Destaque profissional

A seção de Experiências apresenta como principal atuação a Bolsa de Iniciação Tecnológica no QuIIN (Quantum Industrial Innovation), com foco em Redes de Computadores, Cibersegurança e Comunicação Quântica.

## Como executar

Abra `index.html` diretamente no navegador ou use o Live Server no VS Code.

## Foto

O projeto possui uma moldura de foto pronta na pasta visual do Hero. Para adicionar uma foto real, coloque a imagem em `assets/images/` e substitua o bloco `.photo-placeholder` no `index.html`.

## Antes de publicar

- Adicionar a foto profissional.
- Confirmar todos os dados.
- Revisar a descrição da atuação no QuIIN.
- Conferir os links de contato.
